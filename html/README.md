# 🌐 Bản HTML Thuần — EcoLiving Smart Home IoT

Bản giao diện này được xây dựng hoàn toàn bằng **HTML5, CSS3 và JavaScript thuần (Vanilla Web)** dành riêng cho môn học **IoT và Ứng dụng** (Bài Thực Hành 3) của sinh viên **Nguyễn Thị Ngọc Anh (B23DCAT015)**.

---

## ✨ Điểm Nổi Bật Của Bản HTML Thuần Này:
1. **Không cần cài đặt Node.js hay gõ lệnh npm:** Chỉ cần nhấp đúp chuột vào file `index.html` là mở xem và sử dụng ngay lập tức trên bất kỳ trình duyệt nào (Chrome, Safari, Edge, Cốc Cốc).
2. **Đầy đủ 4 Tab nghiệp vụ:**
   - **Bảng điều khiển (Dashboard):** 3 Thẻ cảm biến (Nhiệt độ, Độ ẩm, Ánh sáng), 3 Thẻ điều khiển (Quạt, Đèn, Điều hòa) kèm công tắc iOS mượt mà, Biểu đồ Chart.js trực quan.
   - **Dữ liệu cảm biến:** Bảng dữ liệu lịch sử đo đạc, tìm kiếm từ khóa, lọc theo loại cảm biến và phân trang.
   - **Nhật ký hành động:** **Lọc tức thì ngay khi chọn thiết bị/hành động/trạng thái** mà không cần nhấn nút tìm kiếm!
   - **Hồ sơ cá nhân:** Thông tin sinh viên PTIT, mã sinh viên B23DCAT015, kỹ năng và liên kết đồ án.
3. **Thư viện biểu đồ:** Sử dụng **Chart.js** (tự động tải qua CDN).

---

## 🚀 Cách Mở Và Sử Dụng:

### Cách 1: Mở trực tiếp (Nhanh nhất)
1. Mở Finder hoặc File Explorer trên máy.
2. Đi tới thư mục: `home-iot/html/`
3. Nhấp đúp chuột vào file **`index.html`**.

### Cách 2: Mở bằng VS Code Live Server
Nếu bạn đang dùng VS Code:
1. Chuột phải vào file `index.html`.
2. Chọn **"Open with Live Server"**.
