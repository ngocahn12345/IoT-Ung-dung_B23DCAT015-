Tài Liệu Đặc Tả API EcoLiving Smart Home

Hệ thống REST API phục vụ giám sát cảm biến môi trường DHT11 / BH1750, điều khiển thiết bị ngoại vi qua MQTT và đo lường độ trễ phản hồi phần cứng (ACK) trong đề tài môn IoT & Ứng dụng.

Sinh viên: Nguyễn Thị Ngọc Anh
Mã SV: B23DCAT015
Base URL: http://localhost:5050
Xác thực: x-api-key (Header)
POST /api/login
Công khai (Public)

Xác thực tài khoản người dùng và sinh mã phiên làm việc chữ ký điện tử HMAC-SHA256 (tiền tố eco_...). Tự động lưu vào Postman Environment.

Tham số Request Body (JSON / form-urlencoded)
Tên trườngKiểuBắt buộcMô tả
usernameStringCóTên đăng nhập (Mặc định: admin)
passwordStringCóMật khẩu xác thực (Mặc định: 123)
Ví dụ cURL
curl -X POST http://localhost:5050/api/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin", "password":"123"}'

    "full_name": "Nguyễn Thị Ngọc Anh",

POST /api/logout
Yêu cầu API Key

Thu hồi token API Key hiện tại ngay lập tức. Mọi yêu cầu tiếp theo mang API Key này sẽ bị từ chối với mã 401 Unauthorized.

Ví dụ cURL
curl -X POST http://localhost:5050/api/logout \
  -H "x-api-key: {{api_key}}"

GET /api/sensors/history
Yêu cầu API Key

Tra cứu lịch sử đo đạc từ cơ sở dữ liệu MySQL (11.550+ bản ghi). Hỗ trợ tìm kiếm từ khóa số đo, lọc theo loại cảm biến, sắp xếp và phân trang.

Tham số Query (Query Parameters)
Tên tham sốKiểuMặc địnhMô tả
pageInteger1Số thứ tự trang cần lấy
limitInteger10Số bản ghi mỗi trang
sensor_typeStringTất cảLọc: TEMPERATURE, HUMIDITY, hoặc LIGHT
searchStringTrốngTìm kiếm từ khóa giá trị đo (Ví dụ: 27)
sort_byStringdata_idCột sắp xếp (data_id, timestamp, value)
sort_orderStringDESCThứ tự sắp xếp (ASC hoặc DESC)
Ví dụ cURL
curl -X GET "http://localhost:5050/api/sensors/history?sensor_type=TEMPERATURE&search=27&page=1&limit=10" \
  -H "x-api-key: {{api_key}}"
POST /api/control
Yêu cầu API Key

Gửi lệnh điều khiển phần cứng tới vi điều khiển ESP32 qua giao thức MQTT. Lắng nghe phản hồi phần cứng (ACK) và tính toán độ trễ phản hồi (Response Latency).

Tham số Request Body (JSON)
Tên trườngKiểuBắt buộcGiá trị hợp lệ
device_keyStringCó (hoặc device_id)led1 (Điều hòa), led2 (Quạt), led3 (Đèn)
action_typeStringCóON (Bật) hoặc OFF (Tắt)
modeStringKhôngMANUAL (Thủ công) hoặc AUTO (Tự động)
Response mẫu (200 OK)
{
  "success": true,
  "message": "Điều khiển thiết bị Quạt thông gió (LED 2) thành công.",
  "action_id": 182,
  "device_id": 2,
  "status": "ON",
  "activation_time": "2026-11-19 14:45:00.120",
  "response_time": "2026-11-19 14:45:00.620",
  "latency_seconds": 0.50
}
GET /api/actions/history
Yêu cầu API Key

Tra cứu lịch sử 182+ bản ghi thao tác điều khiển thiết bị kèm thời gian kích hoạt, thời gian phản hồi phần cứng và độ trễ chính xác.

Ví dụ cURL
curl -X GET "http://localhost:5050/api/actions/history?page=1&limit=10" \
  -H "x-api-key: {{api_key}}"
